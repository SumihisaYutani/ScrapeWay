# ScrapeWay

Web の小説を、公開されたときの形のまま手元に保存して、オフラインで読むための Windows アプリです。

- **pixiv 小説**：作者の全作品・シリーズ・1話をまとめて保存。新しい話や更新された話だけを保存することもできます（R-18 作品はログインが必要）。
- **Wayback Machine**：閉鎖した昔の個人サイトの小説を、アーカイブから保存。目次からのリンクをたどってまとめて保存し、消えた後の記録（404 や閉鎖のお知らせ）は飛ばして、消えていない最新の版を保存します。

取得したデータは原本として手を加えずに残し、読むためのページ（縦書き・文字サイズ・配色の切り替えつき）は別に作ります。

## 使い方

[取扱説明書](docs/manual.html) を参照してください。

## ビルド

必要なもの：Qt 6（Core / Gui / Widgets / Network / Concurrent）、CMake 3.21 以上、C++20 コンパイラ

- **Qt Creator**：`CMakeLists.txt` を開いてビルド（Qt 6.10.3 MinGW / MSVC2022 で確認済み）
- **配布用**：`build.bat` を実行すると、`dist\ScrapeWay\`（実行に必要な DLL 一式）と `dist\ScrapeWay.zip` ができます。Qt 6.10.3 MSVC2022 と Visual Studio 2022 のパスを前提にしているので、環境に合わせて書き換えてください。

設計と内部の仕様は [仕様書](docs/specification.md) にまとめています。

## ご注意

- 保存した作品の著作権は作者にあります。個人的に読む範囲で使ってください。
- 取得の間隔を短くしすぎないでください（既定は 3 秒）。pixiv や Wayback Machine に負荷をかけると、制限や利用停止の対象になります。
