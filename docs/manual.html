ScrapeWay 取扱説明書

Web の小説を、公開されたときの形のまま手元に保存して、オフラインで読むためのアプリです。

1. ScrapeWay でできること

サイトできること
pixiv 小説作者の全作品・シリーズ・1話を、まとめて保存します。新しい話や更新された話を見つけて、その分だけ保存することもできます。R-18 作品も、ログインすれば保存できます。
Wayback Machine
（インターネットアーカイブ）		今はもう無い昔の個人サイトの小説を、アーカイブから保存します。目次ページから各話へのリンクをたどって、まとめて保存できます。

保存した小説は、インターネットにつながっていなくても読めます。読むときは、縦書き・文字の大きさ・配色を切り替えられます。

保存するときは、元のデータを手を加えずにそのまま残し、読むためのページはそれとは別に作ります。サイトが消えても、元の形の記録が残ります。

2. 準備と起動

必要なもの

  • Windows 10 または 11（64 ビット）
  • pixiv にログインする場合：Google Chrome または Microsoft Edge（Windows に最初から入っています）

ほかのソフトのインストールは要りません。

はじめて使うとき

  1. ScrapeWay.zip を右クリックして「すべて展開」を選び、好きな場所に展開します（例：ドキュメント の中）。
  2. 展開した ScrapeWay フォルダの中の ScrapeWay.exe をダブルクリックすると起動します。
  3. 「Windows によって PC が保護されました」と表示されたら、「詳細情報」→「実行」を押してください（このアプリには電子署名がないため表示されます）。
ヒントScrapeWay.exe を右クリックして「送る」→「デスクトップ（ショートカットを作成）」を選ぶと、次からはデスクトップから起動できます。
フォルダの中身は動かさないでくださいScrapeWay.exe と同じフォルダにある DLL ファイルやフォルダは、アプリが動くのに必要です。exe だけを別の場所に移すと起動しません。

4. pixiv にログインする

全年齢の作品は、ログインしなくても保存できます。R-18 作品を保存するときは、ログインが必要です。ログインは最初の1回だけで、次からは自動でログインした状態になります。

  1. 右上の ログイン を押します。
  2. ログイン専用の Chrome（Chrome が無い場合は Edge）が開いて、pixiv のログイン画面が表示されます。メールアドレスとパスワード、または「Google でログイン」などでログインします。
  3. pixiv のトップページが表示されたら、そのブラウザを右上の × で閉じます。
  4. アプリが自動でログインを確認します（数秒かかります）。右上の表示が「● pixiv: あなたの名前」に変われば完了です。
このブラウザはログイン専用です普段お使いの Chrome とは別のものとして開くので、普段の Chrome のログイン情報やブックマークには影響しません。普段の Chrome でログインしていても、このアプリでもう一度ログインする必要があります。

ログイン情報を消したいときは、メニューの「アカウント」→「ログイン情報を削除」を選びます。

5. pixiv の小説を取り込む

  1. Chrome で、保存したい作品や作者のページを開き、アドレスバーの URL をコピーします（Ctrl+C）。
  2. ScrapeWay に切り替えると、コピーした URL が自動で入ります（入らないときは 貼り付け を押します）。
  3. 読み込む を押すと、作品の一覧が出ます。
  4. 保存したい話にチェックが入っていることを確かめて、選択した N 話を保存 を押します。

使える URL

保存するものURL の例
作者の全小説https://www.pixiv.net/users/12345678
シリーズ全話https://www.pixiv.net/novel/series/1234567
1話だけhttps://www.pixiv.net/novel/show.php?id=12345678

一覧の見かた

シリーズごとにまとまって表示されます。シリーズ名の横のチェックで、そのシリーズ全体をまとめて選べます。

状態意味最初のチェック
（空欄）まだ保存していない入っている
更新あり保存したあとで作者が書き直した入っている
保存済み保存した時から変わっていない入っていない

上のボタンで、選択をまとめて変えられます。

  • 未保存と更新ありを選択：まだ保存していないものと、更新されたものだけを選びます。
  • すべて選択：全部を選びます。保存済みのものを選ぶと、上書きして保存し直します。
  • 選択解除：全部の選択を外します。
新しい話が出たか調べるにはライブラリで作者名を右クリックし、「新しい話・更新を確認」を選びます。新しい話と更新された話だけにチェックが入った一覧が出るので、そのまま保存を押すだけです。

6. Wayback Machine から取り込む

Wayback Machine（web.archive.org）は、昔の Web ページを記録しているサービスです。閉鎖したサイトの小説も、ここに残っていれば保存できます。

  1. Chrome で Wayback Machine を開き、保存したい小説の目次のページを表示します。
  2. アドレスバーの URL をコピーします。https://web.archive.org/web/20050101123456/http://… のような形です。
  3. ScrapeWay に切り替えて 読み込む を押します。一覧が出るまで数十秒かかることがあります。
  4. 保存したいページにチェックを入れて、選択した N ページを保存 を押します。

一覧の見かた

グループ内容最初のチェック
開いたページURL を入れたページ（目次など）入っている
このページからのリンクそのページのリンク先（目次なら各話）。リンクの文字が題名として表示されます入っている
同じフォルダ内のその他の保存ページリンクはされていないが、同じフォルダに残っているページ入っていない（必要なら選んでください）
状態意味
保存済みもう保存してある
Wayback になしリンクはあるが、Wayback Machine に一度も記録されていない（保存できません）
  • 小説の本文が別のフォルダにあって一覧に出てこないときは、一つ上のフォルダも含めて一覧にする を押してください。
  • ページと一緒に、同じサイトの画像・背景・BGM なども保存されます（Wayback に記録されているものだけです）。
  • 昔のサイトによくある Shift_JIS・EUC-JP などの文字コードは、自動で判別します。文字化けせずに読めます。
どの時期の版が保存されるかWayback Machine には、同じページが何度も記録されていることがあります。ScrapeWay は、ページごとに消えていない一番新しい版を保存します。後の記録が「ページが見つかりません」「閉鎖しました」「移転しました」などのお知らせになっている場合は、それを飛ばして、その前の正常な版を保存します（ログに「○○ の版は消えたページのようです」と表示されます）。保存されるのは最新の1つだけで、昔の版は残りません。

一覧の「最初の記録」の列は、そのページが初めて記録された日です。実際に保存された版の日付は、ログ（「保存: 題名（2019/01/01 の版）」）とライブラリの「更新日」で確かめられます。保存済みのページを選んでもう一度保存すると、その時点の最新の版に更新されます（変わっていなければ取得し直しません）。

7. 保存の進み具合と中止

保存を始めると、取り込みタブの下の「保存の進行状況」に表示されます。

  • サイトに負担をかけないよう、1件ずつ、決まった間隔（初めは 3 秒）をあけて保存します。100 話なら約 5 分かかります。
  • 保存中も、ほかの URL を読み込んだり、次の保存を予約したりできます。予約した保存は順番に行われます。
  • やめたいときは、一覧で選んで 選択した作業を中止 を押します。それまでに保存した分は残ります。
  • 右側の「ログ」に、保存した題名や失敗の理由が表示されます。
  • 保存中にアプリを閉じようとすると、確認が出ます。閉じると保存は中止されます（保存済みの分は残ります）。

8. ライブラリで探す・読む

「ライブラリ」タブに、保存した作品がすべて表示されます。

表示並び
pixiv作者 → シリーズ（または単発作品）→ 話。新しく更新されたものが上に来ます。
Waybackサイト → フォルダ → ページ
  • 読む：話やページをダブルクリックすると、ブラウザで開きます。
  • 探す：上の検索欄に、題名・作者名・シリーズ名・タグの一部を入れると絞り込めます。
  • 右クリック：「第1話から読む」「フォルダを開く」「pixiv で開く」「Wayback で開く」「新しい話・更新を確認」などが選べます。

9. 読書画面の使いかた

pixiv の小説は、読みやすい専用の画面で開きます。上のボタンで表示を変えられます。

ボタン働き
縦書き / 横書き縦書きと横書きを切り替えます。縦書きのときは、マウスのホイールで左右に送れます。
A− A＋文字を小さく／大きくします。

選んだ設定は次に開いたときも引き継がれます。シリーズの話には、上下に「← 前の話」「次の話 →」のリンクがあります。ルビ・改ページ・章の見出し・挿絵も、pixiv と同じように表示されます。

Wayback から保存したページは、当時のデザインのまま表示されます。上に黄色い帯で、記録された日付と「保存したページの一覧」へのリンクが出ます。

10. 設定

設定変えかた
保存先のフォルダ「ファイル」→「保存先フォルダを変更…」。初めは ドキュメント\ScrapeWay です。変更しても、今までに保存したファイルは移動しません（必要なら、エクスプローラーで新しいフォルダに移してください）。
取得の間隔取り込みタブの「取得間隔」（1〜60 秒）。最後に使った値を覚えています。短くしすぎないでください（13章）。

USB メモリなどで持ち歩く（ポータブル版）

ScrapeWay.exe と同じフォルダに、portable.txt という名前の空のファイルを作ってください（メモ帳で何も書かずに保存すれば作れます）。次からは、設定とログイン情報を ScrapeWay フォルダの中の data に保存するようになり、フォルダごと持ち運べます。保存先のフォルダも ScrapeWay フォルダの近くに変更しておくと便利です。

11. 保存されるファイル

保存先フォルダ（初めは ドキュメント\ScrapeWay）の中に、次のように保存されます。エクスプローラーで直接開いて、ほかのソフトで使うこともできます。

pixiv

pixiv\ 12345678_作者名\ series_1234567_シリーズ名\ 001_23456789_第一話の題名\ content.txt ← 本文（pixiv に投稿されたままの文章） meta.json ← 題名・キャプション・タグ・日付などの情報 novel.html ← 読むためのページ（ダブルクリックでブラウザで開けます） cover.jpg ← 表紙 images\ ← 挿絵

Wayback Machine

wayback\ www.example.jp\ index.html ← 保存したページの目次 view\ ← 読むためのページ（文字化けしないように直したもの） original\ ← 記録されていたファイルそのもの（当時の文字コードのまま） site.json ← 保存の記録
読むためのページは自動で作り直されますnovel.html と view\ は、元のデータからアプリが作っています。消してしまっても、次にアプリを起動したときに作り直されます。content.txt・meta.json・original\・site.json は元のデータなので、消さないでください。

12. 困ったときは

「このブラウザまたはアプリは安全でない可能性があります」と出て、Google でログインできない
古い版の ScrapeWay で起きていた問題です。最新の版を使ってください。最新の版でも出る場合は、pixiv のログイン画面で、Google ではなくメールアドレス（pixiv ID）とパスワードでログインしてください。
ログインしたのに「pixiv へのログインが確認できませんでした」と出る
pixiv のトップページが表示されてから、ブラウザを閉じてください。ログイン画面のまま閉じると確認できません。もう一度 ログイン を押すと、前回のログイン状態が残っていれば、すぐ閉じても確認できます。
「ログイン用のブラウザが既に開いているようです」と出る
前に開いたログイン専用のブラウザが、どこかに開いたままになっています。そのブラウザを閉じてから、もう一度 ログイン を押してください。
作者の URL を読み込んだのに「小説が見つかりません」と出る
その作者の作品が R-18 だけの場合、ログインしていないと 0 件になります。4章の手順でログインしてください。ログインしているのに出る場合は、ログインの有効期限が切れている可能性があります。再ログイン を押してください。
Wayback の一覧がなかなか出ない
Wayback Machine の検索は時間がかかることがあります（1 分前後）。それでも出ない場合や、エラーになる場合は、Wayback Machine が混み合っているので、少し時間をおいて試してください。
「Internet Archive が一時停止中のため、60 秒待ってやり直します」と出る／保存が途中で止まった
Internet Archive（Wayback Machine）が混雑して、一時的に止まっています。しばらく待っても戻らない場合、ScrapeWay は保存を打ち切ります（保存済みの分は残ります）。時間をおいて同じ URL を読み込み、「未保存と更新ありを選択」→ 保存で続きから再開できます。
保存の進行状況の数字がなかなか増えない
ログを見てください。「HTTP 502 のため 10 秒待ってやり直します」のような表示が出ていれば、Wayback 側が応答しないファイルを待っている最中です。止まっているわけではありません。何も表示が出ず、「保存の進行状況」が空なら、保存は実行されていません。一覧でチェックを入れて「保存」を押してください（「同じフォルダ内のその他の保存ページ」には、最初はチェックが入っていません）。
Wayback の一覧に、読みたい話が出てこない
一つ上のフォルダも含めて一覧にする を押してください。それでも出ない場合や「Wayback になし」と表示される場合は、その話は Wayback Machine に記録されていません。
Wayback から保存したページの画像が表示されない
その画像は Wayback Machine に記録されていなかったため、保存できませんでした。ログに「画像などの取得に失敗」と出ています。
Wayback から保存したページが文字化けする
アプリを起動し直してください（起動するときに、読むためのページが作り直されます）。それでも直らない場合は、ページの URL を開発者に知らせてください。
保存の途中で「失敗」が出た
ログに理由が表示されます。「HTTP 429」などは、サイトが混雑しているかアクセスが多すぎる印です。取得間隔を長くして、もう一度読み込んで保存してください（保存済みの分は自動で飛ばされます）。
起動しない／「○○.dll が見つかりません」と出る
ScrapeWay フォルダの中身がそろっていません。zip ファイルをもう一度展開して、フォルダごと使ってください。

13. ご注意

  • 保存した作品の著作権は、作者にあります。保存は、自分で読むためなど個人的な利用の範囲にとどめてください。保存したファイルを他の人に渡したり、インターネットに公開したりしないでください。
  • 取得の間隔を短くしすぎないでください。短時間にたくさんのアクセスをすると、pixiv や Wayback Machine から制限を受けたり、アカウントが利用停止になったりすることがあります。初めの 3 秒のままで使うことをおすすめします。
  • ログイン情報を他人に渡さないでください。設定のフォルダ（%APPDATA%\ScrapeWay。ポータブル版は data フォルダ）には、pixiv にログインした状態が保存されています。ポータブル版を他の人に渡すときは、data フォルダを消してから渡してください。
  • pixiv や Wayback Machine の仕組みが変わると、保存できなくなることがあります。

アンインストール

  1. ScrapeWay フォルダを削除します。
  2. 設定とログイン情報も消すときは、エクスプローラーのアドレス欄に %APPDATA%\ScrapeWay と入力して開き、そのフォルダを削除します。
  3. 保存した作品（ドキュメント\ScrapeWay）は、必要なければ削除してください。
